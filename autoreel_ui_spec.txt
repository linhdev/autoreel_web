WORKFLOW SECTION
----------------
Title:
"Mot AutoReel. Ba workflow chinh."

3 cards equal visual priority.

1) Affiliate Flow
Icon: shopping bag/cart
Headline:
"Tu san pham -> Video -> Dang ban"
Mini flow:
San pham -> AI Content -> Video -> Caption -> Shopee/Facebook
Features:
- bulk video
- AI voice
- subtitle
- caption
- publish

2) Reup / Repurpose Flow
Icon: repeat/recycle
Headline:
"Bien video co san thanh noi dung moi"
Mini flow:
Video -> Highlight/Dub/Branding -> Final Video -> Publish
Features:
- YouTube/TikTok/local file
- highlight
- dub
- subtitle
- branding
- logo/text

Use "Repurpose" prominently enough so product feels professional,
not positioned around copyright infringement.

3) AI Review Flow
Icon: film/play/sparkles
Headline:
"Mot video nguon -> Nhieu video moi"
Mini flow:
1 video -> AI Analyze -> Rewrite -> N Scripts -> N Videos -> Publish
Features:
- analyze original script/content
- rewrite variants
- voice/speed/music
- caption/publish
